Warum das wichtig ist

Ein Link auf deiner Website führt auf eine Seite, die es nicht gibt. Besucher landen auf „Seite nicht gefunden“, und Google folgt dem Link umsonst.

So behebst du es

Öffne die Seite, auf der der Link steht (siehe Liste), und trag die richtige Adresse ein oder lösch den Link. Gibt es das Ziel unter neuer Adresse, hilft zusätzlich eine Weiterleitung von der alten Adresse.

In WordPress: Seite bearbeiten → verlinkten Text anklicken → Stift-Symbol → neue Adresse eintragen oder Link entfernen. Steht der Link im Menü: Design → Menüs (bei Block-Themes: Design → Editor → Navigation).
